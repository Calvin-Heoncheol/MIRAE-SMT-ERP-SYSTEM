# 모달 폼 레이아웃 규칙

ErpModal 기반 입력 모달의 그리드·스크롤·섹션 기준입니다.

## ErpModal size

| size | 폭 | 용도 |
|------|-----|------|
| `form` | ~512px | 필드 ≤6, 짧은 마스터 |
| `md` | ~768px | 일반 마스터 |
| `xl` | ~896px | 품목 등 섹션형 폼 |
| `lg` | ~1152px | 헤더 + 라인 표 |
| `wide` | ~1680px | 좌우 분할(견적)만. 필드 2개짜리 헤더에는 쓰지 않음 |

## 그리드

- **1열**: 짧은 폼, 주소·긴 메모·비밀번호
- **2열 (기본)**: 코드\|이름, 일자\|공급사, 구분\|통화 등 짝 필드
- **3열**: 동급 짧은 숫자 3개만 (예: SMD\|후공정\|자재). 연락처 3열 금지
- **4열**: 모달에서 지양 → **2×2** 사용
- **full (`col-span-2`)**: 검색 콤보·주소·비고·긴 읽기전용
- **중첩 금지**: 바깥 2열 그리드 안에 또 2열 그리드를 한 칸으로 넣지 말 것

## 섹션 순서

1. 식별 (구분, 고객, 코드/명)
2. 상업 (단가, 통화, 납기)
3. 운영/기준 (면, 종수, Tech Time) — 부차적이면 접이식
4. 라인/첨부

필수 필드를 선택 식별자보다 앞에 둡니다 (예: 거래처명 → 사업자번호).

## 스크롤

- ErpModal 본문은 기본 `overflow-y-auto` — 필드가 늘면 한 덩어리로 스크롤됨
- **헤더 + 표** 모달: 헤더는 `shrink-0`, 표만 `min-h-0 flex-1 overflow` + sticky thead
- **입력 + 미리보기/이력**: 좌우 분할 (견적·생산입력 참고). 저장 CTA는 왼쪽 패널 sticky 또는 ErpModal footer

## 도움말

- 필드마다 회색 힌트를 붙이지 않음
- 섹션당 1줄, 또는 `description` / `placeholder`로 이동
